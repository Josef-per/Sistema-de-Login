# Sistema de Login

Sistema de autentificação desenvonvido em React, tendo foco em boas práticas de desenvolvimento Front-end, organização de projetos e aplicação de conceitos de segurança do lado do cliente.

## Objetivos

O objetivo desse projeto é treinar a construir um projeto React do zero, passando por todas as configurações iniciais de bundles e compiladores, além disso praticar e desenvolver técnicas de segurança mesmo no front-end.

Por se tratar de um projeto somente de Front-end todas as autentificações serão simuladas, para novas versões possa ser feito uma integração com banco de dados em nuvem ou locais.

## Tecnologias

As tecnologias escohidas para produzir esse projeto foram React, Babel, Esbuild, pnpm e git.

- React : Tecnologia base para a criação do projeto, foco para o desenvolvimento.
- Babel : Compilador / Transpilador escolhido para o desenvolvimento junto ao react.
- Esbuild : Bundler escolhido por sua velocidade e modernidade.
- Pnpm : Gerenciador de pacotes escolhido por sua arquitetura e semelhança ao npm.
- Git : Versionamento do código e manutenção do mesmo.

## Funcionalidades

O projeto está sendo pensado para ter as seguintes funcionalidades segundo a documentação.

- RF01 - Login.
- RF02 -  Cadastro.
- RF03 - Recuperação de Senha
- RF04 - Dashboard.
- RF05 - Perfil.
- RF06 - 404.

De uma forma simples o sistema é pensado para fazer um login/cadastro seguro a uma página, explorando toda a segurança que podemos encontrar dentro ainda do front-end.
