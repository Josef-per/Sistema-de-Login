# Roadmap do Projeto

## 1. Objetivo

Este documento apresenta o roadmap do projeto, descrevendo as principais etapas previstas para o desenvolvimento do sistema. Seu objetivo é fornecer uma visão geral da evolução da aplicação, organizando as funcionalidades e atividades de forma sequencial, desde o planejamento até a entrega da versão final.

## 2. Roadmap

| Etapa                                     | Objetivo                                            | Status       |
|-------------------------------------------|-----------------------------------------------------|--------------|
| 1. Planejamento                           | Documentação inicial completa                       | Em andamento |
| 2. Configuração do projeto                | Ambiente de desenvolvimento configurado e funcional | Não iniciado |
| 3. Desenvolvimento da interface           | Toda a interface responsiva e paginação funcional   | Não iniciado |
| 4. Desenvolvimento das funcionalidades    | Implementação das funcionalidades previstas         | Não iniciado |
| 5. Teste e validação                      | Testar, validar e corrigir inconsistências          | Não iniciado |
| 6. Revisão final e finalização do projeto | Revisão final do projeto para envio                 | Não iniciado |
