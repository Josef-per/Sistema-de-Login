# Modelagem do Banco de Dados (DER)

O modelo do banco de dados está disponível acessando o link [Sistema de Login](https://app.brmodeloweb.com/publicview/6a48162f17f447c2c4dadeb4) , sendo criado no BRMW, para uma visualização rápida e simples do modelo.

## Observação

Apesar da aplicação utilizar armazenamento em memória por meio de listas durante a execução, este modelo foi elaborado para representar como os dados seriam estruturados caso o sistema utilizasse um banco de dados relacional.
